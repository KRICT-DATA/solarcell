## Libary for externally obtained data
This file contains datasets obtained from **external sources (DFT calculation, literature, ...)** related to the design of new perovskite solar cell design.

---
### Currently available dataset lists
- **Dipole_moments_DFT.xlsx** : dataset for dipole moment of molecules used for perovskite synthesis (solvents, passivation)
- **Solvent_Precursor_BindingEnergy_DFT.xlsx**: dataset describing binding energy between solvent molecules and perovskite precursors
- **[TODO] Preovskite_Dataset.csv**: human-curated dataset obtained from the literature (reference: [The Perovskite Database](https://www.perovskitedatabase.com/))
